Café y Pizzas

Sitio web para negocio local de alimentos con menú interactivo, integración con WhatsApp para pedidos y ubicación en Google Maps.

Ver sitio en vivo

Sobre el proyecto

Café y Pizzas es un sitio web desarrollado para un negocio local de alimentos que buscaba incrementar sus ventas y mejorar su presencia digital. El objetivo fue crear una plataforma funcional que presentara el menú de forma clara y facilitara el contacto con clientes.

El sitio cuenta con menú interactivo de productos, integración directa con WhatsApp para pedidos, ubicación con Google Maps y un espacio para promociones y ofertas especiales. También incluye una sección de productos adicionales como joyería.

Diseñado con enfoque en usabilidad y conversión, el proyecto demuestra la capacidad de construir sitios funcionales para negocios locales con necesidades específicas.
