Sobre el proyecto

El Sistema de Tickets es un módulo desarrollado para Odoo 17 que permite a las empresas gestionar solicitudes, problemas y tareas de soporte de manera organizada y eficiente.

Con una interfaz intuitiva, flujo de trabajo configurable y seguimiento detallado de actividades, el módulo es la solución ideal para equipos técnicos y de atención al cliente. Permite categorizar, asignar y resolver tickets rápidamente, mejorando la productividad y garantizando un historial claro de todas las interacciones.

Desarrollado en Python y XML siguiendo los estándares de Odoo, fue publicado en el marketplace oficial, lo que implica revisión de código y cumplimiento de las guías de calidad de Odoo S.A.

Tecnologías usadas

Python XML Odoo 17 PostgreSQL ORM
