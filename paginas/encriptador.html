Encriptador de Texto

App web para cifrar y descifrar mensajes mediante sustitución de caracteres. Interfaz sencilla y funcional desarrollada con JavaScript puro.

Ver app en vivo

Sobre el proyecto

El Encriptador de Texto es una aplicación web que permite a los usuarios cifrar y descifrar mensajes de forma sencilla. El algoritmo de encriptación funciona mediante sustitución de vocales por secuencias de caracteres específicas.

La app acepta texto en minúsculas sin acentos y produce el resultado en tiempo real. El usuario puede ingresar cualquier texto, obtener su versión encriptada y también revertir el proceso para descifrar mensajes recibidos.

Desarrollado con JavaScript puro (sin librerías), este proyecto pone en práctica la manipulación del DOM, manejo de strings y lógica de algoritmos.
